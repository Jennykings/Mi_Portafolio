Desarrollo de un sitio web e-commerce para venta de relojes

Desarrollé una plataforma e-commerce para la venta de relojes utilizando frameworks modernos de front-end y back-end para garantizar una experiencia de compra rápida, segura y responsive. La plataforma incluye navegación por categorías, filtros avanzados, carrito de compras en tiempo real y múltiples métodos de pago, además de un panel administrativo para gestionar productos, stock y pedidos de manera eficiente. Implementé automatización de carga de productos mediante web scraping, permitiendo mantener información actualizada de precios, imágenes y descripciones. Este proyecto demuestra mis habilidades en desarrollo full-stack, optimización de rendimiento, diseño de bases de datos y creación de interfaces intuitivas enfocadas en la experiencia del usuario.

Desarrollo de un sitio web e-commerce para venta de abarrotes

El proyecto consistió en el desarrollo de una plataforma e-commerce diseñada específicamente para la venta en línea de abarrotes. El objetivo fue crear un sitio funcional, accesible y fácil de usar, que permitiera a los clientes realizar compras de productos esenciales desde la comodidad de su hogar. El sitio incluye funcionalidades como navegación por categorías, carrito de compras actualizado en tiempo real, múltiples opciones de pago seguras y una sección de usuario donde los clientes pueden revisar su historial de compras y gestionar sus datos. Además, se integró un panel administrativo intuitivo para la gestión del catálogo de productos, el control de stock y el seguimiento de pedidos.
